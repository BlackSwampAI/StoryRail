# Screenshot notes

These screenshots show real StoryRail interface components rendered with a small, fictional in-memory newsroom. Names, headlines, publication details, source excerpts, and editorial states are illustrative and do not represent a real publisher or persisted StoryRail data.

- `newsroom.png` shows the `NewsroomShell` with a selected in-progress Story, its editorial rail, and current Article.
- `article-provenance.png` shows the `ArticleReader` with the citation support expanded for a cited claim.

The images were captured from the repository's React components and styles in a temporary local browser harness. The harness is not part of the repository; no application data or external service was used.
